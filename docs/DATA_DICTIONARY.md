# Data Dictionary

## Raw files (challenge `dataset/`, not in git)

All files: UTF-8, TAB-separated, one header row, **read with quoting disabled**
(`src/io/data_loader.py` does this). Empty strings are real values (not NaN).

### `{train,test}_source{1,2,3}.tsv`

| column | type | description |
|---|---|---|
| `entity_id` | string | Unique record id. Prefix = source: `S1-` (deduplicated reference), `S2-`, `S3-` |
| `business_name` | string | Business name as the source wrote it. Never empty. May contain Indian scripts, accents, legal forms, trade-name markers, noise |
| `business_address` | string | Free-text address. Empty in ~3% of S2/S3; may contain placeholders `null`, `<NULL>`, `N/A`, `nan`. **No postcodes** |
| `country` | string | Country label. Train: `US`, `India`. Test adds `France`. Treat as an open set |

### `train_ground_truth.tsv`

| column | type | description |
|---|---|---|
| `source1_entity_id` | string | One row per S1 train record |
| `matched_entity_ids` | string | Comma-separated S2/S3 ids of the same business; empty = singleton. Each S2/S3 id appears under at most one S1 |

## Processed files (`data/processed/`, written by `src/preprocessing/preprocess.py`)

`data/processed/<split>/source{k}.parquet` — the 4 original columns **unchanged**,
plus the normalised fields below. `data/processed/train/ground_truth.parquet` —
the ground truth as-is. `data/processed/manifest.json` — row counts and timings.

| field | type | description | example (raw → field) |
|---|---|---|---|
| `name_clean` | string | Lowercase ASCII full name: native script mapped to English (learned vocab, else transliterated), accents folded, digit-for-letter fixed, punctuation removed, legal forms canonicalised, URLs/IDs/honorific prefixes removed | `Nexnex t/a Raka Motors Private Limited` → `raka motors pvt ltd` |
| `name_core` | string | `name_clean` without legal forms, stop words (and/of/the/de/la…), honorifics, country words. Main field for name similarity | → `raka motors` |
| `name_compact` | string | `name_core` without spaces — matches domain-style names | `deepeshagri.com` → `deepeshagri` |
| `name_alt` | string | Cleaned text **before** a trade-name marker (t/a, dba, d/b/a, aka, née, formerly). In this data it is a random brand; kept for completeness | → `nexnex` |
| `name_legal` | string | Sorted canonical legal forms found (`ltd pvt`, `llc`, `sarl` …) | → `ltd pvt` |
| `name_key` | string | Phonetic consonant skeleton of each `name_core` word (lossy on purpose: typo / transliteration robust) | `praivet` and `private` → `prbt` |
| `name_script` | string | Dominant script of the ORIGINAL name: `LATIN`, `DEVANAGARI`, `TAMIL`, … `NONE` | `श्री मीडिया` → `DEVANAGARI` |
| `name_translit` | int8 | 1 if native-script text was converted | |
| `addr_clean` | string | Lowercase ASCII address, placeholders and state removed, street types canonicalised (road→rd, street/saint→st, rue/r→rue …), leading zeros stripped | `#00111 NEWTON STREET, ROSEH ILL, NC` → `111 newton st roseh ill` |
| `addr_core` | string | Address words only: no numbers, state, country, stop words (no, city, town, unit, de, la …) | → `newton st roseh ill` |
| `addr_key` | string | Phonetic skeleton of `addr_core` words | `fillmmore` and `fillmore` → `flmr` |
| `addr_nums` | string | Sorted unique numbers from the address (house / plot / flat / survey numbers) | `242-244 Main St` → `242 244` |
| `addr_state` | string | Canonical admin area: `US-XX`, `IN-XX`, `FR-<region>`; French departments map to their region; native-script state names recognised; `''` if none | `Gironde` → `FR-NAQ`, `महाराष्ट्र` → `IN-MH` |
| `addr_missing` | int8 | 1 if the address is empty or only placeholders | `<NULL>` → 1 |

## Config files (`configs/`)

| file | content |
|---|---|
| `lexicons.json` | Static word lists: legal forms, name/address abbreviations, stop words, placeholders, US states, Indian states + codes, French regions + departments. Generated by `scripts/build_lexicons.py` |
| `translit_vocab.json` | Learned native-script token → English word map. Generated from training matches by `src/preprocessing/translit_vocab.py` (learned on the full training set: 1.24M text pairs) |

## Legacy fields (`src/preprocessing/canonicalize.py`, used by the Phase-1 baseline in `src/pipeline.py`)

| field | status |
|---|---|
| `name_norm`, `addr_norm`, `name_key`, `first_token` | still produced; superseded by `name_core`, `addr_core`, `name_key` (phonetic) above |
| `postcode` | **invalid** — the data has no postcodes; this regex captures house numbers. Use `addr_nums` instead |
